# Multi-currency settlements

If you lend money in different currencies, Rasmerk tracks balances **per currency** for each friend.

## Example

You lend a friend ₹2,000 and later $50. Rasmerk shows two separate balances:
- ₹2,000 outstanding
- $50 outstanding

## Requirements

Multi-currency is a **Premium** feature.

## Recording a multi-currency repayment

When recording a repayment, select the currency the friend paid back in. Rasmerk applies the exchange rate snapshot and updates the correct currency balance.
