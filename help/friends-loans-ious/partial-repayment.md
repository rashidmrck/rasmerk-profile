# Partial repayment

Friends can repay in multiple installments. Rasmerk tracks each payment and keeps a running balance.

## Recording a partial repayment

1. Go to **Friends → select the friend → tap the loan**.
2. Tap **Add Repayment**.
3. Enter the partial amount (less than the full outstanding balance).
4. Select the account where you received the money.
5. Tap **Save**.

## Settlement history

The loan detail screen shows a full timeline:
- Original loan amount and date
- Each repayment: amount, date, account
- Current outstanding balance

## Marking as fully settled

When the balance reaches zero, the loan is automatically marked as **Settled**. You can also manually mark it settled if you choose to waive the remaining amount.
