# Understanding the Dashboard

The Dashboard gives you an instant snapshot of your finances.

## What you see

| Element | What it shows |
|---|---|
| **Total Balance** | Net worth across all accounts |
| **Monthly Income** | Total income recorded this calendar month |
| **Monthly Expense** | Total expenses recorded this calendar month |
| **Safe to Spend** | How much you can spend per day and still meet all budgets |
| **Recent Activity** | Last few transactions |
| **Budget cards** | Progress bars for each active budget |
| **Friends card** | Summary of money owed to/from friends |

## Hide Balance mode

Tap the **eye icon** in the top bar to hide all amounts. All numbers become `••••••`. This is useful in public. The setting resets when the app is closed.
