# Manual SMS Import

You can manually trigger an SMS import to pull recent bank messages.

## How to use

1. Go to **Settings → SMS Import**.
2. Tap **Import Now**.
3. Rasmerk scans your inbox from the configured start date.
4. Recognized transactions appear in your pending list.
5. Unrecognized messages appear in **Needs Review**.

## Free plan limit

The free plan allows **20 SMS imports per month**. This counter resets at the start of each calendar month. Premium removes this limit.

## What happens to unrecognized SMS

If Rasmerk cannot parse an SMS, it still saves it as a **Needs Review** transaction with the raw message body. You can open it, fill in the details, and confirm — or delete it.
