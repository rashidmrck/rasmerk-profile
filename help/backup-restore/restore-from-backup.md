# Restore from backup

Use this when switching to a new phone or after reinstalling Rasmerk.

## Requirements

- Must be signed in with the **same Google account** used for the original backup.
- Google Drive Backup requires **Premium**.

## Steps

1. Install Rasmerk on the new device.
2. Open the app and go to **Settings → Backup → Google Drive**.
3. Tap **Restore**.
4. Rasmerk finds the latest backup from your Google Drive App Data.
5. Confirm the restore — all current data will be replaced.
6. Rasmerk loads your accounts, transactions, budgets, and friends.

## If restore does not find a backup

- Confirm you are signed in with the correct Google account.
- The account must be the same one used when the backup was created.
- Check that the backup was successfully created before the old device was wiped.
