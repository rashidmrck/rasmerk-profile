# Does Rasmerk work offline?

**Yes.** Rasmerk is designed to work fully offline.

All core features work without internet:
- Add, edit, and delete transactions
- View accounts and balances
- Track budgets and spending
- Manage friends and loans
- Receipt scanner (local OCR)
- SMS auto-import parsing

## Features that require internet

| Feature | Internet needed for |
|---|---|
| Google Drive Backup | Upload/download backup |
| Ambassador program | Syncing referral rewards |
| Improve with AI | Sending OCR text to AI API |
| Play Store purchase | Premium IAP purchase |
