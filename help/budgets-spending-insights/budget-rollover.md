# Budget rollover

## Default behavior

Rasmerk budgets are **monthly** and reset at the start of each calendar month. Unused budget from the previous month does not carry over.

## Example

You set a ₹5,000 food budget and spend ₹3,200 in July. On August 1, the budget resets to a fresh ₹5,000 — the ₹1,800 unused does not add to August.

## Why no rollover?

Monthly budgets are designed to set a consistent spending intention, not to accumulate savings. If you want to track savings, use a dedicated **savings account** with a deposit transaction at month end.
