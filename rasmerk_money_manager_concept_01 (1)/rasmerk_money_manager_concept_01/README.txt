Concept 01 – Smart Wallet
Money Manager mobile app icon asset package

This package contains a production-ready raster asset set based on Concept 01 – Smart Wallet from the supplied reference. The icon uses the concept’s dark/deep blue wallet, blue layered details, red/orange card element, white curved opening detail, and blue clasp/button. No wordmark or presentation-sheet elements are included.

Note: the supplied reference was a raster/generated presentation image rather than an original vector source. The master icon in this package was reconstructed as a clean transparent raster graphic from the Concept 01 visual direction; it is not claimed to be the original vector master.
