RASMERK — Exact Logo Asset Package
====================================

Source:
- Extracted directly from the supplied reference PNG.
- The original blue/cyan/navy gradients are preserved from the source pixels.
- No AI redraw or approximate logo reconstruction was used.

IMPORTANT:
The source image is raster, not an actual editable vector file. Therefore
the SVG included here is an SVG wrapper containing the exact extracted PNG;
it is NOT a fake geometric re-trace. This is the safest way to preserve the
logo exactly as shown.
